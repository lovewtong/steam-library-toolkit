## 纳入范围

| 功能 | v1.2.0 的行为和边界 |
|---|---|
| 开发商／发行商 | 商店名称数组、逐字段观察证据、AppID 个人校正、精确名称筛选和计划分组；不自动合并简称、大小写或公司关系 |
| 首次观察时间 | 保存同账号可用历史，移除后重现保留日期；支持 UTC 年／月筛选和分组。未知保持未知，日期不代表购买、激活或加入家庭时间 |
| 家庭来源与成员 | 默认核验客户端和家庭来源，将符合资格的家庭游戏并入 `accessible_snapshot`，保留实际成员来源和共享／自有证据；排除条目与家庭非游戏不扩大成员集合 |
| 家庭失败保护 | 身份、家庭、所有者、清单稳定性及截断检查；核验失败保留旧输出。`--no-family` 限定为客户端范围，使用独立输出，不能覆盖已保存家庭库 |
| 分类与证据 | 纳入两款参照游戏 3017860、2183900 的主类／子类校正，内置规则 34→36；其他字段仍按实际证据显示人工确认、推断、未知或生成 |
| 完整性证据校验 | 无效 `completeness` 和计数被拒绝，这类错误证据不触发类型异常或替换旧指针 |
| 既有六项流程 | 继续提供采集、审计、补全、分类校正、本地浏览和收藏计划导出，以及 v1.1.0 的复核清单。新字段与成员规则在表格、页面、CLI、重分类和计划中一致 |
| 文档 | 中英文 README 和用法已说明主线与 v1.1.0 的区别，提供厂商、时间、家庭功能及升级限制的专题说明 |

Windows、本机、单个明确账号的本地授权路径是当前真人验证范围。Linux/macOS 的三平台通过结果属于离线 CI，不宣称真实认证已验收。收藏计划仍是导出文件，`ownership_revalidated=false`、`write_supported=false`。

## 本版本不承诺

- 准确购买日期、许可日期推定、自动 Steam 收藏写回、安装器或自动更新。
- 绝对完整的游戏库、全家庭逐项覆盖或逐游戏可启动保证，以及全库人工分类准确率。
- 多账号切换、Steam 自身离线→在线恢复、自然权益变化和其他系统真实认证已经通过验收。这些场景仍待验证，不会因纳入家庭来源而改为已支持。
- 新家庭规模下的冷缓存耗时保证。旧 R2 和厂商开发计时各有自己的提交、缓存及规模，不能当作此次候选的全库冷性能验收。

## 升级与回退约定

升级前保留旧软件、旧个人配置和完整运行目录：`.current.json` 必须与其引用的隐藏 `.runs` 目录一起备份。首次采集或重建使用新输出路径，不编辑旧运行。

旧运行缺厂商或首次观察字段时保持未知；离线重分类不凭空补日期。需要将已核验旧记录作为首次观察历史时，在新采集中显式使用 `--history-from`，只接受同账号的完整运行。商店缓存为 v6，旧缓存按需重新抓取；首次补全可能较慢。

家庭运行扩展了 schema v2 的成员枚举和证据字段，旧软件可能拒绝。回退使用旧软件、旧配置和旧运行；不保证旧版能读取新家庭产物。独立导入家庭快照仍为历史候选，不能升级为实时成员证明。详细操作见 [用法](../../USAGE.zh.md)、[时间历史](../guides/TIME_CLASSIFICATION.md)和[家庭兼容性](../guides/STEAM_FAMILIES.md#兼容性)。
