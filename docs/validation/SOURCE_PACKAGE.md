# 源码包化与资源归位验收

日期：2026-10-07。实现提交：`cc7e9b9cefd64697f59d60dd16583b55b523a108`。基线：结构整理 PR #15 的 `d47c58a1dd251d6951196393a1cc5773ef82c170`。本报告的文档提交不改变实现。

## 变更

- Python 实现迁至 `src/steam_library_toolkit/`，按 CLI、来源、分类、存储和网页职责分目录；根目录保留八个常用 CLI 及 `_compat.py`。
- 旧 CLI 继续调用同一模块的函数和参数解析器。支持源码目录直接运行，不强制 editable 安装；旧内部模块导入路径改为包内路径。
- HTML、三个 Schema、内置 AppID 规则和六个 Node 桥接模块归入包资源，配置示例移至 `examples/`。这些原资源内容没有修改。
- `pyproject.toml` 定义安装信息和命令，提供 `steam-library`、独立命令与 `python -m steam_library_toolkit`。`1.3.0.dev0` 只是开发构建标识，未发布到 PyPI，也未创建对应 Git 标签或 Release。
- npm 清单、锁文件和分类说明保持唯一源码；构建时复制进 wheel，安装用的 npm 清单去除开发／旧实验快捷命令。
- 源码默认数据目录仍为仓库根目录；安装后默认当前工作目录，可用 `STEAM_LIBRARY_HOME` 指定。Node 依赖独立准备，可用 `STEAM_LIBRARY_NODE_HOME` 指定，正常采集不会自动下载。
- HTTP worker 改为包模块启动，避免直接脚本启动时同目录 `http.py` 遮蔽 Python 标准库；保留截止、取消、重试与子进程清理机制。
- 中英文 README、USAGE、结构说明与个人校正规则指南同步更新。
